🔗 Connecter Google Sheets
Deux méthodes — choisis la plus simple pour toi
1
Dans ton Google Sheets → Extensions → Apps Script
Ouvre le fichier CreditPlus_Team_Dashboard.xlsx dans Google Sheets, puis clique sur Extensions → Apps Script
2
Colle ce code et sauvegarde (Ctrl+S)
function doGet(e) { var callback = e.parameter.callback || 'callback'; var ss = SpreadsheetApp.getActiveSpreadsheet(); var sheet = ss.getSheetByName("KPI_Weekly"); var data = sheet.getDataRange().getValues(); var headers = data[0]; var rows = data.slice(1).map(function(row) { var obj = {}; headers.forEach(function(h, i) { obj[String(h)] = String(row[i] || ''); }); return obj; }).filter(function(r) { return r[headers[0]] !== ''; }); var json = JSON.stringify({ data: rows, status: 'ok' }); return ContentService .createTextOutput(callback + '(' + json + ')') .setMimeType(ContentService.MimeType.JAVASCRIPT); }
3
Redéployer — Gérer les déploiements → ✏️ → Nouvelle version → Enregistrer
L'URL reste la même après le redéploiement.
